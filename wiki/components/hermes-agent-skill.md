# Hermes Agent Interactive SOC Skill

While the [Python AI Analyzer](ai-analyzer-minimax.md) handles 24/7 automated monitoring with the [Zero-Token Pre-Filter](../concepts/zero-token-filter.md), the user's **Hermes Agent** (running on an Ubuntu VM inside an isolated VLAN) acts as an **on-demand interactive SOC analyst**.

---

## 1. Network Isolation & Firewall Rule

To preserve the security isolation of the Hermes VLAN while granting read-only access to security telemetry:
- Only **one** firewall rule is added on pfSense (on the Hermes VLAN interface):
  - `Pass TCP` from `<HERMES_UBUNTU_VM_IP>` to `<DOCKER_HOST_IP>` on destination port **`3100`** ([Grafana Loki](loki-and-grafana.md)).

---

## 2. Zero-Dependency CLI (`hermes_skill/query_pfsense_loki.py`)

Written exclusively with Python 3's standard library (`urllib.request`, `ipaddress`, `json`, `argparse`) so it runs on the Ubuntu VM without requiring `pip` packages:

- **`summary --hours 24`**: Returns aggregated counts across Tier 1, Tier 2, Tier 3 (automatically enriched with **GeoIP Country, City, ISP, and ASN** via batch lookup), and recent AI reports.
- **`inspect-ip <IP> --hours 168`**: Retrieves the 7-day activity timeline, hit counts, targeted ports, and `geoip` attribution for any external or internal IP (RFC1918 addresses are classified locally without external calls).
- **`outbound --hours 24`**: Lists all internal LAN/VLAN devices triggering Tier 1 suspicious outbound rules.
- **`ai-reports --hours 72`**: Retrieves the latest structured security assessments generated by `MiniMax-M3`.
- **`--no-geoip`**: Optional flag on `summary` and `inspect-ip` to disable external GeoIP/ASN batch queries when operating in strictly air-gapped environments.
